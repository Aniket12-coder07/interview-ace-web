# 🎯 InterviewAce - AI Mock Interview Platform

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black) ![Gemini](https://img.shields.io/badge/Gemini_2.0-4285F4?style=for-the-badge&logo=google&logoColor=white)

An AI-powered cross-platform mock interview platform that prepares candidates for senior technical interviews across 7 domain tracks.

## ✨ Features

- 🧠 **AI Mock Interviews** — Powered by Gemini 2.0 Flash with stream-generated role-tailored questions
- 💻 **In-App Coding IDE** — Full code editor with terminal execution and O(N) complexity evaluation
- 🎙️ **Voice-to-Text** — Hands-free voice recording for interview responses
- 📊 **4-Axis Rubric Scoring** — Technical depth, algorithmic complexity, communication & edge cases
- 💳 **RevenueCat Monetization** — Pro subscriptions with weekly, monthly, annual & lifetime plans
- 🏆 **Completion Certificates** — Auto-generated performance certificates
- 📱 **Mobile Responsive** — iPhone simulator view + PWA support

## 🎯 Interview Tracks

| Track | Description |
|-------|-------------|
| AI/ML Engineer | Deep learning, NLP, computer vision |
| Full Stack Developer | React, Node.js, databases |
| Backend Systems | Distributed systems, microservices |
| Data Scientist | Statistics, ML pipelines |
| DevOps Engineer | CI/CD, Kubernetes, cloud |
| Sales Executive | SaaS sales, pipeline management |
| Technical Recruiter | Tech screening, sourcing |

## 🚀 Getting Started

```bash
git clone https://github.com/Aniket12-coder07/interview-ace-web.git
cd interview-ace-web
python -m http.server 8080
```

Then visit `http://localhost:8080`

## 🔧 Setup

1. Get a [Gemini API Key](https://aistudio.google.com/apikey)
2. Open the app → Settings ⚙️ → Paste your API key
3. Select your interview track and start practicing!
