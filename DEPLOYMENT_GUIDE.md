# 🚀 InterviewAce Web - One-Click Deployment Guide

Deploy your InterviewAce AI Mock Interviewer web application instantly to **Vercel** or **Netlify** for free hosting.

## ⚡ Option 1: Deploy on Netlify (Fastest - Drag & Drop)

### Method A: Drag & Drop (Zero Install, 30 Seconds)
1. Go to [Netlify Drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the folder:
   `C:\Users\Neha\.gemini\antigravity\scratch\interview_ace_web`
3. Netlify will instantly publish your site and give you a live production URL (e.g. `https://interviewace.netlify.app`).

### Method B: Netlify CLI
Run the following terminal command from the project root:
```bash
npx netlify-cli deploy --prod --dir=.
```

---

## ⚡ Option 2: Deploy on Vercel

### Method A: Vercel CLI
Run the following terminal command in your terminal:
```bash
npx vercel --prod
```
When prompted:
- Set project root to `./`
- Accept all defaults (No build command required for static sites).

### Method B: GitHub Repository Import
1. Push this folder (`interview_ace_web`) to a GitHub repository.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Select your GitHub repository and click **Deploy**.
