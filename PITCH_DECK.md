## 🌟 What Makes InterviewAce an Award-Winning Project?

### 1. 🤖 Gemini 2.0 Flash Strict Evaluation System
- **Anti-Hallucination & Anti-Cheating**: Assigns strict **0–10 / 100** scores for non-answers ("I don't know", "pass") and unedited template code.
- **Model Answer Benchmarks**: Compares candidate responses against top-tier ideal responses.

### 2. 💻 Integrated Multi-Language Coding IDE
- **In-App Execution**: Run JavaScript code with stdout console output right inside the web/mobile app interface.
- **Multi-Language Syntax Check**: Supports **JavaScript, Python 3, C++ 17, and Java 17**.

### 3. 🔊 Text-to-Speech AI Interviewer & Web Audio SFX
- **Speech Synthesis**: Click the speaker icon on any question to have the AI interviewer read the problem statement aloud in natural voice.
- **Synthesized UI Audio**: Futuristic sound effects when submitting answers, leveling up, or completing sessions.

### 4. 📊 4-Axis Rubric Score Radar Matrix
Evaluates candidates across 4 core technical pillars:
- 🎯 **Technical Depth & Domain Accuracy**
- ⚡ **Algorithmic & Code Time Complexity** ($O(N)$ vs $O(N^2)$)
- 💬 **Communication & Structured Reasoning**
- 🛡️ **Edge Case & System Resilience**

### 5. 📜 Official Printable Certificate of Completion
- Automatically generates an **Official Candidate Certificate of Readiness** with verification ID and score metrics, ready to print or save as PDF!

### 6. 💳 High-Converting RevenueCat Subscription Architecture
- **Entitlement**: `pro_access`
- **Pricing Tiers**:
  - **Weekly Pass**: $1.99 / week
  - **Monthly Pro**: $4.99 / month (**7-Day Free Trial**)
  - **Annual Pass**: $29.99 / year (**Save 50%**)
